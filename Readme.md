Slot Machine Game

This is a 2D slot machine game developed using **Unity**. Spin the reels, match symbols, and win virtual credits!

Game Overview

Lucky Spin is a simple and entertaining slot machine game featuring animated reels, betting options, and a virtual reward system.

Features

- 2D slot machine interface
- Animated spinning reels
- Multiple slot symbols
- Virtual betting system
- Winning combinations and payouts
- Sound effects
- WebGL browser build

Technologies Used

- **Game Engine:** Unity
- **Programming Language:** C#
- **Platform:** WebGL
- **Version Control:** Git & GitHub

How to Play

1. Open the game.
2. Select your bet amount.
3. Press the **Spin** button.
4. Wait for all three reels to stop.
5. Match the symbols to win virtual credits.

Payout System

| Symbol Combination | Reward |
|---|---:|
| Three Sevens | 10x Bet |
| Three Cherries | 5x Bet |
| Three Bells | 3x Bet |
| Three BAR Symbols | 2x Bet |

*Rewards use virtual credits only.*
